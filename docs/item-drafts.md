# Item drafts

The item editor saves unfinished work locally while you edit, when the app goes into the background, and when you close the editor. Drafts retain incomplete field text, supplier details, custom fields, and photos. They do not become inventory items until Save succeeds.

Use **Save Draft** beside **Save** in the existing item editor to retain incomplete work and close the editor without adding inventory.

Use **Drafts** in the bottom bar to resume or delete a draft. **Start new** keeps the current draft and opens a fresh form. Saving an item removes its draft.

**Personalization → Resume latest item draft** is enabled by default. Turn it off to open a fresh form and choose drafts manually. Editing an existing item resumes drafts for that item; adding an item lists unfinished new items.

Drafts are stored on this device, separated by workspace. They are not included in inventory sync or portable inventory exports. The draft list reads only titles and timestamps; photos and field values load when you open a draft.
