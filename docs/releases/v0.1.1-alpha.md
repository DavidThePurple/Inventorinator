Inventorinator v0.1.1-alpha is an early preview for Linux, Windows, and Android.

## What changed since v0.1.0-alpha

- A collapsible, default-collapsed Metrics panel above the search bar,
  showing filament spool count (summed by quantity, not row count, so
  multi-spool stacks count correctly), total units, item records, and
  low-stock count.
- A "Tracked types" chip row on the Metrics panel so any built-in or custom
  item type can be excluded from its stats and charts, persisted per device.
- An overlaid inventory-growth chart on the Metrics panel: per-type
  cumulative trends in hue-rotated shades of the active theme accent, with a
  "Unified" toggle to switch to one aggregate curve for the whole tracked
  inventory.
- A filament Style attribute with a live gradient editor and a pie-chart
  chicklet for coextruded strands.
- A device's session simply failing to refresh no longer silently transfers
  workspace ownership and evicts other devices; that now only happens from
  an explicit "Recover ownership" action.
- Same-field edits from two devices no longer resolve silently - the
  collision is now recorded to the Audit Log.
- "Saved" feedback now covers status, location, lifecycle, and item-detail
  edits, not just quantity changes.

## Remote Sync users: update the server first

Before opening this version against a shared Supabase inventory, back up the
PostgreSQL database and install **schema 15**. The schema bundle attached to
this release contains the updater, connector, and migrations 001-015:

`Inventorinator-v0.1.1-alpha-Supabase-schema15.tar.gz`

1. Download and extract the schema bundle.
2. Run `./install-or-update.sh`.
3. Choose hosted Supabase or a self-hosted Docker stack.
4. Confirm the command ends with `Inventorinator schema v15 is ready.`
5. Then install or launch the app.

The updater applies only missing migrations. Schema is unchanged from
v0.1.0-alpha (still schema 15); this release is an app-only update for
Remote Sync users already on schema 15.

Full instructions: [How to Upgrade](https://github.com/DavidThePurple/Inventorinator/wiki/How-to-Upgrade)

New Remote Sync setup: [Supabase Sync Setup](https://github.com/DavidThePurple/Inventorinator/wiki/Supabase-Sync-Setup)
