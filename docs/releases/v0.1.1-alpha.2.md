# Inventorinator v0.1.1-alpha.2 (unreleased)

## Role builder groundwork

Owners can open Remote Settings → Role builder to create named templates from
View only, Build operator, Inventory editor or Workshop manager presets.
Each permission has an operation description; destructive operations are
marked separately. Templates can be edited, duplicated and deleted.

On server v25, owners can assign saved custom roles to devices.
Existing built-in roles remain authoritative. Ownership, recovery, device
removal and template management are not delegable through a template.

## DigiKey and offline role drafts

Use Add → Search DigiKey to search with your own developer credentials,
select a packaging variant and review the item before saving. Owned quantity
starts at zero; supplier stock and quotes do not become owned quantity or cost.
DigiKey import is confirmed working by the user (September 19, 2026).

Remote Settings → Role builder (local) stores design drafts on this device without
contacting Supabase. Local drafts never grant access or upload automatically.

## Remote Sync upgrade

Back up your PostgreSQL database before applying **schema 30** on the server.
The planned bundle is `Inventorinator-v0.1.1-alpha.2-Supabase-schema30.tar.gz`,
containing the updater, connector and every migration through 030.
This release and its downloads have not been published yet.

From the extracted bundle, replace the server bundle as a complete unit and
run `./apply-migrations.sh`. Confirm `Inventorinator schema v30 is ready.`
before opening the new app. The migrations add draft-role storage, owner-only
supplier credentials, per-device Scratch Pad backup, optional workspace sharing,
and note links to workshop records. Removed-device notes are retained for the
Owner or Admin who removed that device. Existing memberships and inventory data
are unchanged. See [v30 Wiki server update instructions](https://github.com/DavidThePurple/Inventorinator/wiki/Server-Update-v30).

Previous release instructions remain in `v0.1.1-alpha.md`.


## Core workflow completion

Adds permission-enforced custom roles, durable sync conflict review, higher-resolution supplier photo previews with zoom, and local searchable reports with PDF preview/save/share/print. See [completion details](../completion-pass.md) and [server update](../server-update-v25.md).

## Import review and undo

File imports now allow row selection and correction before saving. Import history supports persistent undo of unchanged, unreferenced imported items. Shared undo requires schema 30 and protects newer remote edits. See [import review and undo](../import-review-and-undo.md).
