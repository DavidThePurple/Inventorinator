Runtime libraries statically linked into tesseract.exe
=======================================================

The bundled tesseract.exe is cross-compiled with the MinGW-w64 GCC toolchain and
statically linked, so it carries copies of the following compiler runtime code.
Its other third-party components have their own LICENSE-*.txt files beside it.
