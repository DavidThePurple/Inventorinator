Inventorinator v0.1.0-alpha is an early preview for Linux, Windows, and Android.

## What changed since v0.0.9-alpha

- FilamentColors.xyz swatch search with caching, offline fallback, attribution,
  request throttling, and cooldown handling.
- Searchable Lucide and Material Type icons, plus custom Type icon uploads.
- Desktop `.inventorinator-kit.json` validation, preview, and confirmed import.
- Imported kit parts start at quantity zero with deduplication, source records,
  sections, products, materials, brands, and machines.
- Stronger shared-inventory recovery: ownership survives auth-user deletion,
  stolen-device blocks and audit history remain, and recovery revokes stale
  pairing codes.

## Remote Sync users: update the server first

Before opening this version against a shared Supabase inventory, back up the
PostgreSQL database and install **schema 15**. The schema bundle attached to
this release contains the updater, connector, and migrations 001-015:

`Inventorinator-v0.1.0-alpha-Supabase-schema15.tar.gz`

1. Download and extract the schema bundle.
2. Run `./install-or-update.sh`.
3. Choose hosted Supabase or a self-hosted Docker stack.
4. Confirm the command ends with `Inventorinator schema v15 is ready.`
5. Then install or launch the app.

The updater applies only missing migrations. Schema 13 preserves legacy
locations, schema 14 repairs authenticated entity reads, and schema 15 blocks
obsolete whole-snapshot writers from overwriting newer per-record changes.

Full instructions: [How to Upgrade](https://github.com/DavidThePurple/Inventorinator/wiki/How-to-Upgrade)

New Remote Sync setup: [Supabase Sync Setup](https://github.com/DavidThePurple/Inventorinator/wiki/Supabase-Sync-Setup)
