# Inventorinator v0.1.1-alpha.2 (unreleased)

## Role builder groundwork

Owners can open Remote Settings → Role builder to create named templates from
View only, Build operator, Inventory editor or Workshop manager presets.
Each permission has an operation description; destructive operations are
marked separately. Templates can be edited, duplicated and deleted.

On server v25, owners can assign saved custom roles to devices.
Existing built-in roles remain authoritative. Ownership, recovery, device
removal and template management are not delegable through a template.

## DigiKey and offline role drafts

Use Add → Search DigiKey to search with your own developer credentials,
select a packaging variant and review the item before saving. Owned quantity
starts at zero; supplier stock and quotes do not become owned quantity or cost.
Live DigiKey account verification is pending.

Remote Settings → Role builder (local) stores design drafts on this device without
contacting Supabase. Local drafts never grant access or upload automatically.

## Remote Sync upgrade

Back up your PostgreSQL database before applying **schema 26** on the server.
The planned bundle is `Inventorinator-v0.1.1-alpha.2-Supabase-schema26.tar.gz`,
containing the updater, connector and every migration through 025.
This release and its downloads have not been published yet.

From the extracted bundle run `./install-or-update.sh`, select your hosting
mode, and confirm `Inventorinator schema v26 is ready.` before opening the
new app. The migrations add draft-role storage, owner-only supplier credentials,
and per-device Scratch Pad backup. Removed-device notes are retained for the
Owner or Admin who removed that device. Existing memberships and inventory data
are unchanged.

Previous release instructions remain in `v0.1.1-alpha.md`.

Before publication, add and verify this version's specific upgrade section
in the project Wiki and link it here.
